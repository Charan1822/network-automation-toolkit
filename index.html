NETWORK AUTOMATION & COMPLIANCE TOOLKIT

Config drift doesn't wait for a ticket.

A Python + Ansible toolkit that backs up device configs, diffs them against a golden baseline, and audits them for compliance — the same checks done by hand across 250+ devices, now version-controlled and repeatable.

View source See what it checks
mock-mode — zero hardware required
WHAT IT DOES

Three checks, one inventory file

Point inventory.yaml at your devices — or run entirely on the bundled mock configs — and each module runs independently.

01 / BACKUP

Timestamped config backup

Pulls the running config over SSH via Netmiko and commits a versioned copy to Git — every change recoverable, nothing overwritten silently.

python src/backup.py
02 / DRIFT

Golden-baseline diffing

Compares the latest backup against a per-role baseline and reports the exact lines that changed — unauthorized changes surface before they cause an incident.

python src/drift.py
03 / COMPLIANCE

Rule-based audit

Checks each device against security rules — Telnet disabled, no default SNMP strings, password encryption on — with a pass/fail report per rule.

python src/compliance.py
